# Project 04: Windows Health Check Toolkit (PowerShell)

## Goal
Build a beginner-friendly PowerShell tool that performs basic PC health checks and creates a report that can be used for troubleshooting.

---

## Skills Practiced
- PowerShell scripting fundamentals
- Windows troubleshooting basics
- Documentation and reporting

---

## What the Script Checks
- Basic system info (PC name, OS version)
- Disk space (C:) with low space warning
- Internet connection test
- Windows Defender status (if available)

---
